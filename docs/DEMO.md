# Demonstration guide

Aim for 7-8 minutes. Record with readable code/UI and clear audio. Team members should speak in their own words and explain the code they reviewed and contributed.

| Time      | Content                                                                                                                     |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 0:00-0:40 | Slide 1: team name/logo, full member names and student IDs, COMP229 Web Application Development, Student Assignment Tracker |
| 0:40-1:10 | Slide 2: current real member photos, names and agreed roles                                                                 |
| 1:10-2:00 | Register/login, demonstrate required fields and incorrect password handling                                                 |
| 2:00-3:30 | Create assignment, list/search/filter, edit details/status, complete/reopen, delete test assignment                         |
| 3:30-4:30 | Show Postman/automated API checks and separate-user ownership protection                                                    |
| 4:30-6:30 | Explain MVC routes/controllers, schemas, bcrypt hashing, JWT HttpOnly sessions, validation and owner-filtered queries       |
| 6:30-7:30 | Show repository and real member commits, live Agile backlog/task board, brief remaining improvements                        |

Create demonstration records with example data. Never display .env or database credentials while recording. Explain that dueDate is a calendar-date string to avoid timezone date shifts. Explain that assignment ownership is enforced on the server, not just hidden in the UI.
