# Agile project board

Live private project: https://github.com/users/vkulesh-netizen/projects/1

The project contains Product backlog (table) and Task board (board) views, linked to the private source repository. Fourteen issues include acceptance criteria and suggested starting owners. Prepared code remains In Progress until the team reviews and contributes; team-dependent and future work starts in Todo.

GitHub Project access is separate from repository access. The owner should give the team and instructor appropriate project access as needed. Keep the board current and export a fresh snapshot before submission.
